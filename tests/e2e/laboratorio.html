Laboratório de testeProteu QA

100%LOCAL

Cada seção exercita uma funcionalidade da extensão. A página observa os campos e valida os documentos com código próprio, sem compartilhar nada com a extensão — se ela gerar um documento errado, aqui acusa.

Abra o popup da Proteu QA, use Preencher formulário e acompanhe o placar acima. O ideal ao final: campos proibidos tocados = 0 e inválidos = 0.

1 Preencher formulário — rotulagem variada

Formulário real nunca é uniforme. Cada campo aqui se identifica de um jeito diferente, para exercitar as três camadas de reconhecimento: autocomplete, type e o texto do campo.

<label for> + name="nome"
rótulo não diz "e-mail" → pega por autocomplete
rótulo não diz "telefone" → pega por type
type=date exige ISO; formato errado é descartado
autocomplete="postal-code"
sem label → pega por placeholder
sem label e sem placeholder → pega por aria-label
irreconhecível: vazio no modo normal, "teste" no modo preencher-tudo

2 Não deve ser tocado — nunca

A extensão não escreve em senha, upload, somente-leitura, desabilitado nem oculto — nem no modo "preencher também os campos que não reconheço". Se o contador de proibidos subir, é bug.

4 Campo controlado por framework

Aqui está o teste que separa a Proteu das outras: este campo guarda o valor num estado próprio e só o atualiza quando recebe um input nativo — como React e Vue fazem. Escrever direto no value, sem disparar evento, deixa o estado dessincronizado e o valor se perde no primeiro re-render.

estado interno: (vazio)
se o valor sumir aqui, a inserção não foi robusta

5 Shadow DOM aberto

O campo abaixo vive dentro de um shadow root aberto. A extensão o alcança porque lê o foco por composedPath(), e não por event.target (que vem "retargetado" para o host).

6 Iframe de mesma origem

A extensão é injetada em todos os frames; quem tem o campo focado é quem insere. Clique no campo de dentro do quadro e gere um valor.

7 Detecção de campo e valores de fronteira

Clique num campo e abra o popup: a extensão lê os atributos e oferece valores de fronteira específicos dele (limite, limite ±1, datas impossíveis, e-mails que passam na regex mas quebram no servidor).

maxlength=10 · required
number · min/max
date com min/max
url
pattern + inputmode
textarea · maxlength=200

9 Menu de contexto e atalhos

Estes dois caminhos não passam pelo popup — se um funciona e o outro não, o problema está no service worker.

  1. Clique com o botão direito no campo abaixo → menu Proteu QA → escolha um documento.
    os itens do menu devem estar no idioma do país ativo
  2. Clique no campo e pressione Ctrl+Shift+8 para repetir a última geração.
  3. Ctrl+Shift+9 abre o popup.

10 Monitor de eventos
